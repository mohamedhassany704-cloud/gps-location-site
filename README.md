# موقع تسجيل GPS — GitHub Pages + Supabase

## الملفات
- `index.html`: واجهة الموقع باللغة العربية.
- `style.css`: التنسيق المتجاوب للموبايل والكمبيوتر.
- `app.js`: يطلب إذن الموقع ثم يرسل الإحداثيات إلى Supabase.
- `supabase.sql`: إنشاء الجدول وسياسة السماح بإضافة السجلات.

## 1) إعداد Supabase
1. أنشئ مشروعًا في https://supabase.com/
2. افتح **SQL Editor**، والصق محتوى `supabase.sql`، ثم اضغط **Run**.
3. افتح إعدادات المشروع وابحث عن **Project URL** ومفتاح **anon / publishable**.
4. افتح `app.js` وعدّل:
   - `SUPABASE_URL` إلى رابط مشروعك.
   - `SUPABASE_ANON_KEY` إلى مفتاح anon/publishable.
5. لا تضع مفتاح `service_role` أو أي مفتاح سري داخل ملفات الموقع.

## 2) نشر الموقع مجانًا
1. أنشئ مستودعًا جديدًا على GitHub، مثل `gps-location-site`.
2. ارفع الملفات الأربعة إلى جذر المستودع (Root).
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع. غالبًا سيكون بالشكل:
   `https://YOUR-USERNAME.github.io/gps-location-site/`

## 3) الاختبار
1. افتح رابط GitHub Pages من الهاتف.
2. اضغط «تسجيل موقعي الآن» واسمح بإذن الموقع.
3. تحقق من ظهور رسالة النجاح.
4. افتح Supabase → **Table Editor → locations** وتأكد من وصول سجل جديد.

## ملاحظات أمان وخصوصية
- تحديد الموقع يحتاج HTTPS وإذنًا صريحًا من المستخدم. GitHub Pages يوفر HTTPS.
- مفتاح `anon/publishable` مخصص للاستخدام من الواجهة، لكنه ليس سرًا؛ الحماية تعتمد على RLS.
- السياسة الحالية تسمح لأي زائر بإضافة سجل، ولا تسمح له بقراءة السجلات. يمكن إساءة استخدامها لإرسال سجلات وهمية أو كثيرة؛ لموقع إنتاجي، أضف تحققًا/حدًا للمعدل أو اجعل التسجيل للمستخدمين المسجلين فقط.
- حقل `device` يحفظ معلومات المتصفح (User-Agent). احذفه من `app.js` والجدول إن لم تكن تحتاجه.
- لا توجد طريقة موثوقة للحصول على GPS إذا عطّل المستخدم إذن الموقع أو رفضه.
